# Dayresi

登録不要・その日だけ使える Web レジ。文化祭の模擬店のように、一日だけレジが欲しいときに使います。

**https://shunsukenaka.github.io/Dayresi/**

## なぜ作ったか

大学の文化祭で出店するときは、アプリを作り慣れた人がレジを作るか、現金と紙で管理していました。既存の POS アプリは登録や契約が必要で、一日だけ使うには大げさです。Dayresi は、登録も契約もせず、直前に決まった商品をすぐ登録してレジを用意できるようにします。迷ったときは手軽さを優先し、便利でも手順が増えるものは足しません。

目的や届けたい人の詳しい内容は [docs/mvp-design-doc.md](docs/mvp-design-doc.md)、仕様は [SPEC.md](SPEC.md) を参照してください。

## できること

- **商品の登録**：商品名と価格（税込）だけを登録する。割引券は「割引 −50円」のように、マイナスの価格の商品として登録できる
- **会計**：商品ボタンを押してカートに入れ、数量を増減する。画面のテンキーや金額ボタンでお預かり金額を入れると、おつりを表示する
- **会計の取消**：確定したあとの会計を、履歴から取り消せる。取り消した会計は「取消済」として残り、集計には入らない
- **集計**：売上合計・会計件数と、商品別の数量・金額を見られる
- **CSV の保存**：売上明細を CSV で保存できる（Excel で開いても文字化けしない）
- **全データの消去**：商品と会計をすべて消せる

在庫管理、割引・セット価格、レシートの発行、支払方法の区別などはありません。

## 使い方

1. **準備**：「設定」で商品を登録する
2. **当日**：「レジ」で商品を選び、「会計」でお預かり金額を入れて「会計確定」を押す。お預かり金額を入れずに確定すると「ちょうど」として扱う。間違えたら「履歴」で取り消して打ち直す
3. **終了後**：「集計」で売上を確認し、「設定」の「売上CSVを保存」でファイルに残す。使い終わったら「全データを消去」で消す

## データと動作環境

- アカウント登録はいりません
- データはその PC のブラウザ内（localStorage）にだけ保存し、サーバーには送りません。別の端末やブラウザとは共有されません
- 一度ページを開けば、インターネットにつながらなくても動きます
- PC 1台でマウスで操作することを想定しています

## 開発

Node.js 24 が必要です。

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果の確認（オフライン動作もここで確認できる）
```

## 公開（GitHub Pages）

1. GitHub にリポジトリを作って `main` ブランチを push する
2. リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
3. 以降は `main` に push するたびに `.github/workflows/deploy.yml` がテスト・ビルド・公開を行う

`base: './'` にしているので、リポジトリ名を変えても設定変更は不要です。
