# 0027. 端末のあいだでデータを共有する機能は MVP で扱わない

- 日付: 2026-10-23
- 状態: 採用

## 背景

SPEC には「事前準備（商品設定の持ち込み）」があり、別の端末で登録した商品を設定ファイルに書き出して、レジの PC で読み込めた。MVP を考えたときの内容を Design Doc にまとめる中で（0026）、この機能を MVP に入れるかを決める必要があった。

## 決めたこと

- 端末のあいだでデータを共有する機能は MVP に入れない。商品設定ファイルの書き出し・読み込みを MVP から外し、商品はレジの PC で直接登録する
- SPEC.md の「事前準備」をなくし、「MVP で扱わないもの」に書く
- 売上 CSV の保存は残す（端末のあいだでデータを共有するためではなく、終了後に売上を残して代表に送るための機能なので）
- 作り直しの Issue のうち、商品設定ファイルのもの（#19・#30・#36）を閉じる（#48）
- 今のコードから書き出し・読み込みを消す作業は、あとで別に行う

## 検討した他の案

- 商品設定ファイルの書き出し・読み込みを残す（今の SPEC のまま）
- 売上 CSV の保存も外し、売上は集計画面で見るだけにする

## 理由
- 初期段階では一人、一か所で使う想定でいるから
