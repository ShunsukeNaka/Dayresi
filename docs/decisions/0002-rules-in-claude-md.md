# 0002. 開発ルールを CLAUDE.md に置く

- 日付: 2026-10-10
- 状態: 採用

## 背景

実装を進めるためのルールを、どこに書いておくか決める必要があった。

## 決めたこと

リポジトリ直下の `CLAUDE.md` に書いてコミットする。

## 検討した他の案

- 人向けのルールは `CONTRIBUTING.md` に書き、`CLAUDE.md` からそれを参照する
- `CLAUDE.local.md` など、コミットしないファイルに置く

## 理由

理由は記録していない。提案時に示した判断材料：Claude Code が毎回自動で読み込み、GitHub 上でも見える。
