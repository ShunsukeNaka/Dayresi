# 0030. 1 つの PR には 1 つの目的だけ持たせる

- 日付: 2026-10-25
- 状態: 採用

## 背景

PR #79 に、#51 の「商品のデータ形式」と「選んだ技術を記録するルール」（0029）を一緒に入れた。ユーザーから「ひとつの PR には一つの目的しか持たせてはいけない」と言われ、このルールを Claude のメモリだけに残すか、CLAUDE.md に書くかを決める必要があった（#83）。

## 決めたこと

- 1 つの PR には 1 つの目的だけ持たせる。作業中に別の目的が出てきたら、同じ PR に入れず、Issue にして別の PR にする
- このルールを CLAUDE.md の「ブランチと PR」に書く

## 検討した他の案

- Claude のメモリにだけ残し、CLAUDE.md は変えない
