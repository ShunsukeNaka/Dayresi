# 0007. npm パッケージの追加は事前に承認をとる

- 日付: 2026-10-10
- 状態: 採用

## 背景

npm パッケージの追加をどう扱うか決める必要があった。

## 決めたこと

新しい npm パッケージを追加する前に、理由を示して承認をとる。

## 検討した他の案

- 必要なら確認なしで追加してよいことにする

## 理由

理由は2つ。

１．セキュリティ
セキュリティ意識から、変なライブラリが入らないかを確認できるようにはしておきたい。

２．学びのため
自分自身の学びのためのプロジェクトという側面もあるので、機能を実現するためにどんなパッケージが使われるのかを知っておきたい。
あとから確認するのは意外と大変だなと感じているため、先に確認しておきたい。
