# 0014. MVP の完了条件は、見直した SPEC の通りに公開されていることにする

- 日付: 2026-10-18
- 状態: 採用

## 背景

MVP の実装はほぼできているが、何ができたら「MVP ができた」とするかが決まっていなかった。また、ユーザージャーニーマップ（issue #5）で分かったことを、SPEC にまだ全部は反映していなかった。

## 決めたこと

- 次の2つを満たしたら MVP ができたとし、SPEC.md の「MVP の完了条件」に書く
  - SPEC の通りに実装され、GitHub Pages で公開されている
  - SPEC が、ユーザージャーニーマップに合わせて見直されている

## 検討した他の案

- 本番を想定して、PC 1台で商品登録から CSV 保存までをオフラインも含めて通しで試し、問題がないこと
- ほかの人（研究室のメンバーなど）に試してもらうこと
- 新しいデザイン（`docs/design/dayresi.pen`）を実装に反映していること

## 理由
- ユーザージャーニーマップをMVPに反映していなかったので反映した。
