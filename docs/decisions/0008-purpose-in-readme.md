# 0008. プロダクトの目的を README.md にまとめる

- 日付: 2026-10-10
- 状態: 採用

## 背景

このプロダクトの目的をまとめる資料を、どこかに用意したかった。

## 決めたこと

- `README.md` に「目的」の節を置く
- 中身は Claude が対話で聞き取ってまとめる

## 検討した他の案

- 目的専用の `docs/PURPOSE.md` を作る
- `SPEC.md` の先頭に「目的」の節を足す
- Claude Docs（リポジトリ外のドキュメント）にする
- 書き手：Claude は枠だけ用意する／Claude が下書きして自分で直す

## 理由

- プロダクトには、明確なターゲットや目的が必要であるため。
- 私がプロダクトに持たせたいコアバリューを明確にするために、ターゲットを定めたい。
- 私がこのプロダクトを開発しようと考えたストーリーを文書化しておくことでClaudeにもコンテキストを共有しておきたい。
