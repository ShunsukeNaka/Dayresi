# 0025. データの形式は、今の形式との互換を前提にせずに考え直す

- 日付: 2026-10-19
- 状態: 採用

## 背景

MVP を作り直す（0022）。すでに使った人の端末に残る保存データ（localStorage の `dayresi:v1`）や、配った商品設定ファイル（version 1）を、新しい実装でも読めるようにするかを決める必要があった。

## 決めたこと

- 今の形式で読めることを前提にしない。MVP に沿って、データの形式を #15〜#20 で考え直す
- 古い保存データ・商品設定ファイルをどう扱うかも、それぞれの Issue（#18、#19）で決める

## 検討した他の案

- 保存データと商品設定ファイルの両方を読めるようにする
- 商品設定ファイルだけ読めるようにする
- どちらも読まない
