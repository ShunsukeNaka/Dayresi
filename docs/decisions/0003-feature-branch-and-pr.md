# 0003. main に直接 push せず、機能ブランチと PR で進める

- 日付: 2026-10-10
- 状態: 採用

## 背景

`main` に push すると GitHub Actions で GitHub Pages に即公開される。

## 決めたこと

- `main` に直接コミット・push しない
- 作業ごとに `main` から機能ブランチを切り、PR を作ってマージする

## 検討した他の案

- 1人開発なので `main` に直接コミット・push する（push すると即公開）
- Claude はコミットまでにして、push とマージは自分で行う

## 理由

理由は記録していない。提案時に示した判断材料：`main` への push は即公開になる。
