# 0001. 意思決定を ADR で記録する

- 日付: 2026-10-10
- 状態: 採用

## 背景

開発中の意思決定を、その都度あとから見返せる形で残したい。

## 決めたこと

- 判断1件につき1ファイルの ADR を `docs/decisions/` に置く
- 選択肢を出して決めたときは、その場で ADR を書き、同じ PR に含める
- これまでの判断（0002〜0007）もさかのぼって記録する

## 検討した他の案

- `docs/DECISIONS.md` 1ファイルに日付つきで追記する：ファイルは増えないが、長くなると探しにくい
- `SPEC.md` に書き足す：SPEC.md は「今どうなっているか」を書く場所なので、経緯を混ぜると読みにくくなる
- PR や Issue の本文に残す：GitHub 上にしか残らず、リポジトリの中から探しにくい
- Claude のメモリに残す：その PC の中だけにあり、他の人からは見えない

## 理由

理由は記録していない。提案時に示した判断材料：リポジトリの中に残せて、1件ずつリンクでき、置き換えの経緯もたどれる。
