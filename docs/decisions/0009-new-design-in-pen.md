# 0009. デザインファイルは pen.dev で新しいデザイン案として作る

- 日付: 2026-10-13
- 状態: 採用

## 背景

画面デザインを確認・検討するためのデザインファイルを、pen.dev（`.pen` 形式）で `docs/design/` に用意することにした。そのデザインを今の実装に合わせるか、新しい案にするかと、どこまで描くかを決める必要があった。

## 決めたこと

- `docs/design/dayresi.pen` に、今の UI とは別の新しいデザイン案を作る
- 入れるのはコンポーネントと全画面（レジ・会計・履歴・集計・設定）のライトモード版
- 実装への反映は別の作業にする（このファイルは案の段階）

## 検討した他の案

- 方向性：今の UI（`src/index.css`）をそのまま再現する／再現と新しい案の両方を並べる
- 範囲：デザイントークン（ライト・ダークのテーマ切り替え）、ダークモード版の画面も入れる

## 理由
AIと共同で開発を行う上で、どのセッションでも同じデザインを共有できるようにするためにデザインファイルを用意した。pen.dev はMCPが利用できるため採用。
基本的には、デザインの調整を個別にAIと行っていこうと思っている。
