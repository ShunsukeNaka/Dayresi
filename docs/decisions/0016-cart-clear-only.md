# 0016. カートの削除は、一括のクリアだけにする

- 日付: 2026-10-18
- 状態: 採用

## 背景

SPEC には「カート内で数量の増減・削除ができる」とあったが、実装には行ごとの削除ボタンがなく、「−」で数量を0にするか、「クリア」でカートを一括で空にするしかなかった。SPEC と実装のどちらに合わせるかを決める必要があった。

## 決めたこと

- 行ごとの削除ボタンは足さず、今の実装に SPEC を合わせる
  - 数量を0にするとカートから消える
  - カートは一括でクリアできる

## 検討した他の案

- 行ごとの削除ボタンを足す（個数が多いときに一度で消せるが、カートのボタンが1つ増える）

## 理由
- MVPをメインターゲットに絞るため。
