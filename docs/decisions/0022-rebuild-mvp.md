# 0022. MVP を作り直す

- 日付: 2026-10-19
- 状態: 採用

## 背景

MVP の完了条件（0014）を満たしたあと、MVP に向けた Issue を「データの形式 → API → 画面」の順に、細かく立てることになった。MVP はすでに実装されて公開されており、SPEC ではサーバーもバックエンドも持たないため、どんな Issue を立てるかを決める必要があった。

## 決めたこと

- MVP を作り直す想定で Issue を立てる（#14〜#45、マイルストーン「MVP 作り直し」）
- サーバーは作らない。「API」は、画面から呼ぶ `src/lib` の関数のこととする
- 進め方と、今の保存データ・商品設定ファイルとの互換は #14 で決める

## 検討した他の案

- 今の実装に足りないもの（SPEC とのずれ、テスト不足、画面の崩れなど）を Issue にする
- サーバーの API を作る（SPEC の「必ず守ること」を変える必要がある）
