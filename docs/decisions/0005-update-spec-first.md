# 0005. 仕様の変更は実装前に SPEC.md を更新する

- 日付: 2026-10-10
- 状態: 採用

## 背景

実装と `SPEC.md` の関係をどう扱うか決める必要があった。

## 決めたこと

- 仕様の変更・追加は、実装する前に `SPEC.md` を更新して合意をとる
- `SPEC.md` の「必ず守ること」と「MVP で扱わないもの」に反する実装はしない

## 検討した他の案

- 実装と同じコミット・PR で `SPEC.md` を更新すればよいことにする
- `SPEC.md` は参考資料として扱い、特に決めない

## 理由

理由は記録していない。
