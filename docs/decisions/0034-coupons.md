# 0034. 次の段階では割引券を作り、マイナスの価格の商品をやめる

- 日付: 2026-10-26
- 状態: 採用

## 背景

ユーザージャーニーマップで、模擬店で「会計から一律50円引き」の割引券を使っていたことが分かっていた。MVP では割引機能を扱わず、商品の価格をマイナスにもできるようにして、「割引 −50円」を商品として登録して代用することにしていた（0011）。0011 の理由には「MVP のあとで検討したい」とあり、#7 で検討を続けていた。

## 決めたこと

- MVP の次の段階で、割引券を作る（仕様は docs/spec-next.md「割引券」「商品の価格」）
- 割引の種類は、金額引きと % 引きの両方にし、割引券ごとに選ぶ
- 代表者が設定で割引券を登録し、商品と一緒に配る。会計ではカートで選んで使う
- 1 回の会計で、金額引きは何枚でも、% 引きは 1 枚まで使える。% 引きを先にかけ、引く金額の 1 円未満は切り捨てる。割引が合計より大きいときは、合計を 0 円で止める
- 商品の価格は 0 円以上に戻し、マイナスの価格の商品はやめる。今あるマイナスの価格の商品は、同じ名前・金額の金額引きの割引券に移す
- 0011 は、この ADR で置き換える（MVP の範囲では 0011 のまま）

## 検討した他の案

- 割引の種類：金額引きだけ／% 引きだけ
- 使い方：会計のたびに引く金額をその場で入れる
- マイナスの価格の商品を残す（割引券と両方使えるようにする）
- % 引きの端数：10 円単位で切り捨て／四捨五入
- 使える枚数：どの割引券も何枚でも／1 回の会計で 1 枚だけ
- 割引が合計より大きいとき：確定できないようにする（MVP の「合計が 0 円未満の会計は確定できない」を引き継ぐ）
- 今あるマイナスの価格の商品：商品として残す／消す
