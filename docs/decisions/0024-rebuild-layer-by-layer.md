# 0024. 作り直しは、層ごとに今のコードを置き換えて進める

- 日付: 2026-10-19
- 状態: 採用

## 背景

MVP を作り直す（0022）。`main` に push するとすぐ公開されるので、作り直している間の進め方を決める必要があった。

## 決めたこと

- 新しい型や関数で、今のコードを層ごとに直接置き換える（データの形式 → ロジック → 画面）
- Issue ごとの PR で、公開版が今までどおり動く状態を保つ。データの形を変えるときは、それを使う今のコードも同じ PR で直す

## 検討した他の案

- 新しいコードを `src/` とは別のフォルダに作り、Issue ごとに `main` へマージする。最後（#45）に入れ替える
- 作り直し用のブランチに Issue ごとの PR をマージし、最後に `main` へマージする
