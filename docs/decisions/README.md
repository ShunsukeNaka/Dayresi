# 意思決定の記録（ADR）

あとで「なぜこうしたのか」を見返せるように、判断の経緯をここに残す。

## 書き方

- 判断1件につき1ファイル。ファイル名は `連番4桁-英語の短い名前.md`
- 下のテンプレートをコピーして書く
- 一度書いた内容は書き換えない。方針を変えるときは新しい ADR を作り、古いほうの「状態」を「NNNN で置き換え」にする
- 記録するのは、あとで理由を思い出せなくなりそうなもの（仕様の範囲、技術選定、データ形式、UI の大きな方針、開発の進め方など）

## テンプレート

```markdown
# NNNN. タイトル

- 日付: YYYY-MM-DD
- 状態: 採用

## 背景

何を決める必要があったか。

## 決めたこと

## 検討した他の案

## 理由
```
