# 0004. コミット前のチェックは lint とテストの追加・更新にする

- 日付: 2026-10-10
- 状態: 採用

## 背景

コミット前に必ず通すチェックを決める必要があった。

## 決めたこと

- `npm run lint` を通す
- `src/lib` のロジックを変えたら、テストを追加・更新する

## 検討した他の案

- `npm test` と `npm run build` もコミット前の必須にする：採用しなかった

## 理由

理由は記録していない。

## 補足

`npm test` と `npm run build` は `main` への push 時に GitHub Actions で実行される。PR の段階では実行されないため、失敗はマージ後に分かる。PR でも実行したくなったら、別のワークフローを追加して検討する。
