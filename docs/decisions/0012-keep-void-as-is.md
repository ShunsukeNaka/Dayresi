# 0012. 会計の間違いは今の取消のままで直す

- 日付: 2026-10-15
- 状態: 採用

## 背景

ユーザージャーニーマップ（issue #5）のヒアリングで、会計の入力の間違いが全体の2割ほど起き、自作のレジでは CSV を書き換えられるレジを作った人しか直せなかったことが分かった。間違いには会計の直後に気づくことがほとんどで、「直前の会計を取り消して打ち直す」のが一番楽という声があった。Dayresi の取消をどこまで簡単にするかを決める必要があった。

## 決めたこと

- SPEC の「確定後の会計を取り消せる」のままにし、SPEC は変えない
  - 今も接客する人を含めて誰でも「履歴」から取り消せるので、「レジを作った人しか直せない」は解消している
  - 打ち直しは、カートに手で入れ直す
- 取り消した会計の中身をカートに戻す機能は足さない

## 検討した他の案

- 取り消した会計の中身をカートに戻し、直して確定し直せるようにする（SPEC の取消に「打ち直し」を足す）
- 対応しない（困りごととしては対応しないと記録する）
