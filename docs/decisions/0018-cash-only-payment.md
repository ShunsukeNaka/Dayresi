# 0018. 支払方法は分けず、現金と同じように記録する

- 日付: 2026-10-18
- 状態: 採用

## 背景

SPEC では、会計のときに支払方法を「現金」「その他（キャッシュレス等をまとめて記録）」から選ぶことになっていた。一方、ユーザージャーニーマップ（issue #5）では、PayPay で受け取った分は店員個人が送金を受け、あとでその分の現金をレジに入れていた。記録でも支払方法を分けず、それで困ったことはなく、現金と記録のずれもなかった。

## 決めたこと

- 支払方法の選択（「その他」）をなくし、キャッシュレスで受け取った分も現金と同じように記録する
- 支払方法の区別は、SPEC.md の「MVP で扱わないもの」に書く
- 実装（会計画面、保存データ、売上 CSV の支払方法の列）は別の PR で直す

## 検討した他の案

- 今のまま残す（初期値が現金なので、使わなければ手順は増えない。実装の変更もない）

## 理由
- MVPをメインターゲットに絞るため。
