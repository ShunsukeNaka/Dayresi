# 0019. 利用シーンを文化祭の模擬店に絞る

- 日付: 2026-10-18
- 状態: 採用

## 背景

SPEC の利用シーンは「学園祭・模擬店、同人誌即売会」だったが、ユーザージャーニーマップ（issue #5）で調べたのは文化祭の模擬店だけで、同人誌即売会は調べていない。利用シーンに同人誌即売会を残すかを決める必要があった。

## 決めたこと

- SPEC.md の利用シーンを「文化祭・学園祭の模擬店」にし、同人誌即売会は外す

## 検討した他の案

- 残す（マップでは調べていないが、利用シーンとしては想定しておく）

## 理由
- ユーザージャーニーマップの作成時にターゲットとして含んでいないため。
