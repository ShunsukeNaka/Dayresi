# 0017. 経費の記録・利益の計算を「MVP で扱わないもの」に書く

- 日付: 2026-10-18
- 状態: 採用

## 背景

ユーザージャーニーマップ（issue #5）で、学祭実行委員への報告フォーマットに「売上の合計」と「経費・利益」の項目があると分かった。Dayresi で出せるのは売上の合計だけで、経費・利益は扱っていない。これを SPEC に書くかを決める必要があった。

## 決めたこと

- 経費の記録・利益の計算は、SPEC.md の「MVP で扱わないもの」に書く

## 検討した他の案

- 書かない（そもそもレジの役割ではないので、触れない）

## 理由
- MVPをメインターゲットに絞るため。
