# 0023. Issue の作業中に決めたことは、その Issue にも書く

- 日付: 2026-10-19
- 状態: 採用

## 背景

Issue 駆動で開発することにした（0021）。Issue の作業中に決めたことを、ADR のほかにどこに残すかを決める必要があった。

## 決めたこと

- ADR の扱いは今までどおり（0001）
- Issue の作業中に決めたことは、ADR に加えてその Issue にもコメントで書く（示した選択肢、決めたこと、ADR へのリンク）

## 検討した他の案

- 意思決定は Issue に書き、ADR をやめる
- 選択肢や理由のやりとりは Issue で行い、結論だけを ADR にまとめる
- ADR は大きな判断だけにし、細かい判断は Issue に書く
