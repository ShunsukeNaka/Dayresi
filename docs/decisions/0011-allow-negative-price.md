# 0011. 商品の価格をマイナスにもできるようにする

- 日付: 2026-10-15
- 状態: 採用

## 背景

ユーザージャーニーマップ（issue #5）のヒアリングで、模擬店で「会計から一律50円引き」の割引券を使っていたことが分かった。会計のたびに「割引」ボタンを押す必要があり、押し忘れが入力の間違いの原因の一つになっていた。また、割引がないと Dayresi は使わないという声があった。SPEC では割引を「MVP で扱わないもの」にしており、商品の価格は「税込」としか書いておらず、マイナスの価格を登録できるかは決まっていなかった（今の実装は0円以上のみ）。

## 決めたこと

- 割引機能は「MVP で扱わないもの」のままにする
- 商品の価格をマイナスにもできるようにし、「割引 −50円」のような商品として登録して代用できるようにする
- 合計が0円未満になる会計は確定できないようにする
- SPEC.md を先に更新し、実装は別の PR で行う

## 検討した他の案

- 対応しない（割引は MVP で扱わず、価格も0円以上のまま）
- 割引機能を MVP に入れる（会計に割引の入力欄を足し、「MVP で扱わないもの」から割引を外す）

## 理由
- 文化祭などでは割引券を渡して集客しようみたいなノリが一定数存在すると思う。やることが難しくなくて集客効果があって思いつきやすいから？
文化祭などで使われることを想定するならば、割引を想定した機能があることはいいと思うがコアバリューからは遠そうな感じがする。アドバンスな機能だと思う。
なので、MVPには入れない。ただ、自分が文化祭で出店するときには割引券を使うこともあってMVPのあとで検討したい。
