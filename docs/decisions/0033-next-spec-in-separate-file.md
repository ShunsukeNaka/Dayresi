# 0033. MVP の次の段階の仕様は、docs/spec-next.md に書く

- 日付: 2026-10-26
- 状態: 採用

## 背景

SPEC.md は MVP の目標として扱い、MVP のあとでやることは SPEC.md の「MVP で扱わないもの（今後の検討事項）」に書くことにしていた（0028）。MVP の次の段階で、代表者が集計する方式とスマホ対応を作ることにした（0032）ので、その仕様をどこに書くかを決める必要があった。

## 決めたこと

- MVP の次の段階の仕様は、新しいファイル [docs/spec-next.md](../spec-next.md) に書く。SPEC.md は MVP の仕様のまま残す
- docs/spec-next.md には、SPEC.md から変わるところと足すところだけを書く
- 0028 のうち「MVP のあとでやることは SPEC.md の『MVP で扱わないもの』に書く」の部分を、この ADR で置き換える。「SPEC は MVP の目標として扱う」は変えない
- CLAUDE.md から docs/spec-next.md にリンクする

## 検討した他の案

- SPEC.md を次の段階の目標に書き換え、MVP の仕様は記録として別のファイルに移す（0028 を置き換える）
- SPEC.md の中に「MVP の次」の節を足す
