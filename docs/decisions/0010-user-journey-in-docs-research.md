# 0010. ユーザージャーニーマップは docs/research/ に Markdown で置く

- 日付: 2026-10-14
- 状態: 採用

## 背景

届けたい人の解像度を上げるために、ユーザージャーニーマップを作ることにした（issue #5）。誰を主人公にするかと、マップをどこにどの形式で置くかを決める必要があった。

## 決めたこと

- 主人公は大学の文化祭で模擬店を出す学生で、次の2つの役割を1枚のマップに並べる。出店が決まってから、終了後の報告・片付けまでを対象にする
  - レジを用意する人：準備の段階でレジを選んで用意し、集計・報告まで受け持つ
  - 接客する人：当日、接客したその場でレジを操作して会計する
- マップは `docs/research/user-journey.md` に Markdown の表で書く

## 検討した他の案

- 主人公：模擬店で会計を担当する人／レジを用意する人だけ／接客して会計する人だけ／模擬店の代表者／同人誌即売会の出展者
  - はじめは「会計を担当する人」にしたが、自分の出店経験を書き出したところ会計の担当者はおらず、接客した人がその都度会計していたので、2つの役割に分けた
- 置き場所・形式：`docs/design/` に pen.dev の図として描く／Markdown と pen.dev の両方

## 理由
ユーザージャーニーマップを作成することで、ユーザーが感じている課題感を明確にしたい。
課題が明確になることによって届ける価値を明確にすることができる。
今回は自分自身がユーザーになるため、昨年に大学の文化祭で出店した経験をもとにユーザージャーにマップを作成している。
ターゲットをレジを用意する人と接客する人の両方にしているのは、文化祭のような環境ではどちらも同じ人が行うことが多いと考えているから。
また、単発のレジを欲しているのはレジを用意する人であるがレジとしての価値を届けるのは接客する人である。
