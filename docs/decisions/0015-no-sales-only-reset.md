# 0015. 商品を残したまま売上だけを消去する機能は MVP で扱わない

- 日付: 2026-10-18
- 状態: 採用

## 背景

用意する人が本番前に試しに会計すると、その記録を消す方法が「全データを消去」しかなく、商品の設定まで消えてしまう。商品を残したまま売上だけを消せるようにするかを決める必要があった。

## 決めたこと

- MVP では扱わず、SPEC.md の「MVP で扱わないもの」に書く

## 検討した他の案

- 設定の「データ」に「売上を消去」ボタンを足し、商品は残す
- 今のまま。商品設定をファイルに書き出してから全データを消去し、読み込み直す（または試した会計を取消で集計から外す）。「MVP で扱わないもの」にも書かない

## 理由
- MVPをメインターゲットに絞るため。
