# 0013. 届けたい人は、用意する人をメイン、接客する人をサブのターゲットにする

- 日付: 2026-10-17
- 状態: 採用

## 背景

ユーザージャーニーマップ（issue #5）で、出店する学生には役割が2つあると分かった。準備の段階でレジを選んで用意する「用意する人」と、当日その場で使い方を聞いて会計する「接客する人」。README の「届けたい人」は「文化祭などで一日だけレジが欲しい人」だけだったので、この2つの役割をどう扱うかを決める必要があった。

## 決めたこと

- 「届けたい人」は「文化祭などで一日だけレジが欲しい人」のままにし、その下に2つの役割を別々の見出しで書く
- 用意する人をメインターゲットにし、最優先にする
  - 出店の準備でレジを選んで用意し、集計も受け持つ人。登録や契約をせず、直前に決まった商品をすぐ登録してレジを用意したい
- 接客する人（レジを使う人）をサブターゲットにする
  - 当日、その場で使い方を聞いて会計する人。使い方を覚えなくても会計でき、間違えたら自分で直したい
- MVP ではメインターゲットを優先する

## 検討した他の案

- 2つの役割を同じ重みで並べる
- 用意する人だけを届けたい人にする（「文化祭などの出店で、一日だけ使うレジを用意する人。当日は、そのレジでメンバーが交代で会計する」）
- 今のまま。ほかの出店者へのヒアリングが済むまで変えない
